Start here

StereoMask works on an existing side-by-side stereo photograph. It does not turn a flat photograph into 3D. Use a Parallel pair (left eye on the left, right eye on the right) as your source. For a Crossview pair, swap its halves in your image editor before importing; the app’s Swap button changes the display only, while export uses left-eye/right-eye order.

There are two parts to an out-of-window edit:

  1. The frame: a shared outline made with dots. Its horizontal offset between the two eyes sets its apparent stereo depth.
  2. The preserved foreground: extra areas selected separately in each eye, using the Polygonal lasso or Select Brush. Everything inside the frame stays visible, along with those extra areas.

While selecting or painting, you see the full source photograph so you can follow its edges. A green overlay marks preserved areas. The export removes the remaining outside area or fills it with your chosen background. The original photograph is not altered.

Tutorial 1 — Make a basic stereo frame

  1. Choose New (File → New Project) and open your side-by-side image.
  2. Choose Editing Tool → Edit frame. Turn Pan off. If unsure about its pressed appearance, switch to Select Brush and back to Edit frame; choosing Select Brush turns Pan off.
  3. In one eye’s image, right-click four corners in order around the opening you want to keep. With a trackpad, use a two-finger secondary click. The frame closes automatically once it has at least three dots; you do not need to click its first dot again.
  4. Left-drag a dot to move it. Right-click near an existing frame edge to insert another dot. Left-drag empty image space to draw a selection box around several dots. On Mac, Command-click dots adds or removes them from the group.
  5. Set the depth. Select all four frame dots, then hold Shift and drag a selected dot horizontally. This changes disparity—the separation between corresponding frame positions in the eyes—rather than its ordinary position. Use small adjustments and check the stereo view. Anaglyph can help if you have red/cyan glasses.
  6. For a flat window, use Align → Depth on the selected dots to give them the same disparity. Position it at the scene plane you want—for example, the bench the people are sitting on. Depth is judged from the stereo image; the app does not identify the bench automatically.
  7. Click Save. To export this opening with a transparent or solid outside background, choose Select Brush once to activate cutout editing, choose Export background, then Export.

Auto is an alternative starting frame based on stereo overlap. It works only when no frame points exist and still needs you to check the resulting opening and depth. Freehand creates the initial frame by dragging when no points exist; it is different from painting foreground areas.

Tutorial 2 — Let a leg or object extend outside the window

If your frame already has the right depth, keep it. Work on the extra foreground areas next.

  1. Choose Editing Tool → Polygonal lasso and Selection → Add to selection.
  2. Zoom into the object in the first eye. Scroll over that area; use Space + drag to bring it into view.
  3. Left-click along the object’s outline. Use short segments around toes and curved edges. Include only the part that must survive outside the frame, with a small overlap into the frame so the shape connects cleanly.
  4. If a click is wrong, press Delete (or Backspace). It removes the most recent point and segment, keeping the rest. You can also drag the current outline’s points.
  5. Click the first point to close the outline, or press Return, or click Close outline. After closing, its points remain adjustable until applied.
  6. Click Apply selection, or click elsewhere to begin the next outline. The previous selection stays, and its boundary remains visible. Repeat for other legs or objects. Overlapping Add shapes enlarge the preserved area.
  7. To trim an unwanted piece, choose Subtract from selection, draw around that piece, close and apply. This removes extra preservation; it does not erase the opening inside the basic frame. Switch back to Add when finished.
  8. Repeat separately in the other eye. Trace that eye’s own object edge, because its position differs. A matching subject needs appropriate masks in both eyes to avoid uncomfortable stereo rivalry.
  9. Choose Export background → Transparent (PNG), Black, White, or Choose color. Save the editable project and Export the finished pair. Check it in your stereo viewer.

Brush touch-ups

Select Brush preserves the area you paint; Erase Brush removes extra preservation. Both work separately in each eye. Set Size, or press [ to shrink and ] to enlarge the brush. The circular cursor shows its diameter. Brushes are useful for quick cleanup after a lasso.

What Escape does

While an outline is open, Escape cancels only that unfinished outline. If it is already closed, Escape applies and keeps it. Earlier applied selections remain in both cases. The Cancel unfinished button follows this same rule. After applying a polygon, its outline remains visible but its individual points are no longer editable; Undo a recent polygon and redraw it if needed.

Settings

Mask Color, Mask Opacity and Mask Feathering apply to the legacy frame mask. Horizontal/Vertical Padding add outer margins. Interleaving Space adds a gap between the eyes; it does not create an interlaced image. Background Color supplies legacy padding; cutout export instead uses Export background for the outside area and padding. AutoSave saves committed changes to the project. Save your project and export your image

Save writes a .msk file alongside the source image. It contains frame settings, per-eye painted masks and applied lasso boundaries. Keep the original image together with it. Export writes a separate masked side-by-side image, normally named with a _masked suffix. Choose a new name to keep earlier exports.

Save and Export apply a closed pending lasso automatically. An open unfinished outline must first be closed or applied. Uncommitted outline clicks are not a substitute for a saved mask.

Use PNG for transparency. JPEG cannot keep an alpha channel. The exported image does not contain the green selection overlay, dashed outlines or frame dots. Zoom does not reduce its resolution. Lasso contours have antialiased edges; cutout export does not currently provide adjustable feathering of those contours.

Transparent output can be useful in compositing or a viewer that supports alpha. A transparent SBS PNG is still a stereo photograph; this app does not convert it into a VR180 projection.

Check for updates

Choose Help → Check for Updates while connected to the internet. The app checks the version notice in TedInVR/StereoMask-Mac on GitHub. You do not need a GitHub account to check this public repository.

If your version is current, the app says you’re up to date. If a newer version exists, it shows the installed and available versions, update notes, and an Open GitHub button. That opens the download page in your browser. Save your project before replacing the app.

The current downloads are source code, which must be built using the included build command. The checker identifies this clearly; it does not install anything automatically. For a source download, use GitHub’s Code → Download ZIP, unzip it, then run BUILD_BRUSH_VERSION.command from that folder. Follow the repository’s current build instructions.

An internet failure or missing update notice is reported as a failed check, not as “up to date.” Try again later, or use Open GitHub to check the repository yourself.

If something seems wrong

  • Dragging moves the image: Pan is on, or Space/Option is held. Choose your brush or lasso again and release those keys.
  • You cannot start another polygon: close the current outline, then Apply selection or click away from its points. An open outline must be finished before changing eyes.
  • A closed polygon’s points are gone: it has been applied. The preserved area and its dashed boundary remain; use Undo to remove a recent operation.
  • Erase/Subtract does not remove an area inside the frame: the frame always preserves its opening. Move the frame boundary if that opening needs to change.
  • An older project has paint but no dashed outlines: older files may contain only the painted alpha mask. Its original polygon points cannot be reconstructed.
  • The export keeps the full picture: create a frame with at least three points and activate a brush/lasso tool to enable cutout editing. Choose the background and export again.
  • The app crashes before opening: keep the crash report and the build folder’s startup.log and bundle-repair.log. R10 repairs bundled dependency references, but its launch still needs validation on your Mac. Repeatedly clicking Reopen cannot correct a packaging error.
