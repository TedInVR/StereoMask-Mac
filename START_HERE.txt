StereoMask Mac R12 / 2.1.2

1. Keep source/build files in /Applications/StereoMask Development.
2. Save your work and quit all StereoMask windows.
3. Run BUILD_BRUSH_VERSION.command to build, verify, install and launch
   /Applications/StereoMask.app. Use that same app/Dock icon every time.
4. For future source updates, run UPDATE_STEREOMASK.command.
   It uses temporary downloads and updates the same development folder.

New: Selections panel, individual polygon editing/reordering/visibility,
whole-polygon movement, optional paired and Smart lassos, matching export
previews, frame holes and updated Mac help.

Turn Preview Mask OFF to see the whole source while tracing.
Choose Transparent (PNG) for a transparent export; new images default
to Match preview, which uses mask color and opacity.

Help > User Guide explains the tools and Mac shortcuts.
Help > Check for Updates checks the Mac repository; it does not install.

Source release for Apple Silicon. This revision still needs actual Mac
packaging, Finder launch and input verification before a binary release.

First optional step: Stereo Window opens an anaglyph slider. Apply commits
one undoable source-depth adjustment; Cancel leaves it unchanged. Save
the project to keep it. Help explains the new tool and side strips.
