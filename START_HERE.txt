StereoMask Mac R21 / 2.5.0

1. Keep source/build files in /Applications/StereoMask Development.
2. Save your work and quit all StereoMask windows.
3. Run UPDATE_STEREOMASK.command to update, build, verify, install and launch
   /Applications/StereoMask.app. Use that same app/Dock icon every time.
4. To rebuild existing source without downloading, run BUILD_BRUSH_VERSION.command.

New in R21: toolbox drawers, Quick Access favorites, View > Show Grid
(Command+G), and Edit Frame > Outline Frame for three colored outline bands.
Every startup opens File only. Hover over left-rail icons for their names.
Click a drawer icon again to close it; Layout can close all or reset drawers.

Stereo Window opens its depth-adjustment dialog directly. Guided Process
walks through opening, adjusting, framing, foreground selection and export.
Help > User Guide explains all tools. Help > Keyboard Shortcuts spells out
key names and lets you edit shortcuts. Main Menu reaches every control group.

Turn Preview Result OFF to see the whole source while tracing. Use Add/Subtract
with brushes or polygonal lassos separately in each eye. History lists current
selection objects, not a complete Undo timeline. Save Project keeps edits;
Export produces the finished image. Transparent output requires PNG.

View grids are editor-only and never exported. Applied outline frames appear
in Clean Preview and export even when Display in editor is off. Foreground
covers outline bands; the existing image canvas clips all borders/shadows.
Older app versions may discard new outline fields: exchange project copies.

Main Menu > Check for Updates checks the Mac repository; it does not install.
The updater uses temporary downloads and the same permanent development folder.

This is an Apple Silicon source release, not a new prebuilt binary. Actual Mac
packaging, Finder launch, font sizing and physical key/secondary-click delivery
need native confirmation. Existing dependency repair/signing/install checks run
before replacing the installed app.

Help > Support StereoMask offers optional Ko-fi, PayPal and Patreon links for
Ted in VR. All features remain free; no startup requests or embedded checkout.
